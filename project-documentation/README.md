# PeopleDesk project documentation

This folder contains academic documentation for the existing PeopleDesk Employee Record Management System. It does not contain changes to the application.

## Deliverables

- `PeopleDesk-Project-Report.docx` — editable report with student, guide, institution, and academic-year placeholders.
- `PeopleDesk-Project-Report.pdf` — PDF exported from the DOCX using Microsoft Word.
- `PeopleDesk-Project-Presentation.pptx` — 15-slide presentation; diagrams and slide content are editable PowerPoint shapes/text.
- `diagrams/` — seven separate PNG diagrams for reuse.

## Report contents

The report contains the requested 34 numbered sections, from cover material and project overview through architecture, role-based modules, DSA explanations, testing evidence, limitations, conclusion, and references. The conceptual data relationship description is explicitly an in-memory model, not a database schema. The report distinguishes the recorded three phase test results from selected API and browser checks, and marks browser-console, complete device, and every role-screen verification as not verified.
